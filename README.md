# sqlite_demo

Minimal C application demonstrating SQLite integration — creates tables, executes queries, and handles results via callbacks. Useful starting point for adding local persistence to embedded Linux applications.

## Key Technologies

- **Language:** C
- **Database:** SQLite 3
- **Build:** CMake

## Getting Started

```bash
mkdir build && cd build
cmake ..
make
./sqlite_demo
```
